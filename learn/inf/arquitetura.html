🧠 CPU (UCP) – Cérebro

  • UC (Unidade de Controle): busca, decodifica e coordena.
  • ULA (Unidade Lógico-Aritmética): operações matemáticas e lógicas.
  • Registradores: memória interna ultrarrápida.
  • Ciclo da instrução: Buscar → Decodificar → Executar → Armazenar.
UC + ULA + Registradores (interligados por barramento interno)
💡 Macete: “UC comanda, ULA calcula, Registra guarda”. 📌 Decore: a UC busca a instrução na memória, a ULA executa a operação.
📌 Dica de prova: Perguntam muito: “Qual componente é responsável por interpretar as instruções?” → UC.

🧩 Memórias – Hierarquia

  • Registradores: mais rápidos, menores (dentro da CPU).
  • Cache (L1, L2, L3): entre CPU e RAM, acelera o acesso.
  • RAM: volátil, leitura/escrita, principal.
  • ROM: não volátil, somente leitura (BIOS).
  • HD/SSD: secundária, não volátil, maior capacidade.
Hierarquia: mais rápido no topo, maior capacidade embaixo.
💡 Macete: “Registrador é foguete, Cache é avião, RAM é carro, HD é caminhão” – velocidade vs. capacidade.
📌 Decore: RAM é volátil (perde dados), ROM não volátil (guarda BIOS).
📌 Dica de prova: “Memória cache serve para reduzir a diferença de velocidade entre CPU e RAM”.

🔌 Barramentos – Vias de comunicação

  • Dados: transporta os dados propriamente ditos (largura em bits).
  • Endereços: indica onde os dados estão (capacidade de endereçamento).
  • Controle: sinais de leitura/escrita, clock, interrupções.
Três barramentos: dados (azul), endereços (laranja) e controle (cinza).
💡 Macete: “Dados → o quê, Endereços → onde, Controle → como”.
📌 Decore: barramento de endereços com n bits endereça 2ⁿ posições de memória.
📌 Dica de prova: “Largura do barramento de dados afeta a performance” – 32 bits vs 64 bits.

📏 Unidades & Arquitetura

  • Bit → 0 ou 1. Byte = 8 bits.
  • KB = 1024 B, MB = 1024 KB, GB = 1024 MB, TB = 1024 GB.
  • Frequência: Hz, MHz, GHz (ciclos por segundo).
  • Von Neumann: programa e dados na mesma memória (barramento único).
  • Harvard: memórias separadas para instruções e dados.
Von Neumann (programa armazenado) vs. Harvard (barramentos separados).
💡 Macete: “Kilo, Mega, Giga, Tera” – na informática sempre ×1024 (não 1000).
📌 Decore: 1 GB = 1024 MB = 1.073.741.824 bytes.
📌 Dica de prova: “Em Von Neumann, o barramento é compartilhado, o que pode criar gargalo (Von Neumann bottleneck)”.

🖱️ Periféricos (E/S)

  • Entrada: teclado, mouse, scanner, microfone.
  • Saída: monitor, impressora, caixas de som.
  • Mistos (E/S): HD, SSD, pendrive, leitor de CD/DVD, tela touch.
Dispositivos de entrada, saída e mistos (E/S).
💡 Macete: “Entrada → entra dado, Saída → sai dado, Misto → faz os dois”.
📌 Decore: monitor é saída, mas monitor touch é misto (entrada + saída).
📌 Dica de prova: “Impressora é saída, scanner é entrada, HD é misto”.

🎯 Tópicos que mais caem

  • Diferença RAM x ROM: volátil vs não volátil.
  • Funções da ULA e UC: UC controla, ULA opera.
  • Barramentos: dados, endereços, controle – saiba diferenciar.
  • Unidades de armazenamento: conversões (KB, MB, GB, TB).
  • Arquitetura de Von Neumann: programa armazenado na mesma memória.
  • Memória cache: níveis (L1, L2, L3) e sua função.
📌 Super Macete para a prova: “Se a questão falar em decodificar ou controlar → UC. Se falar em calcular ou operação lógica → ULA. Se falar em endereçar → barramento de endereços.”
🔁 Revise sempre: hierarquia de memória, conversão de unidades e ciclos de instrução.
