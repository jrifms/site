📊 Matrizes

Definição: Uma matriz é uma tabela retangular de números dispostos em linhas e colunas. A ordem de uma matriz é dada por m × n (m linhas, n colunas).

A = [aij]m×n

Elemento aij está na linha i e coluna j.

Tipos de Matrizes

  • Matriz linha: 1 × n.
  • Matriz coluna: m × 1.
  • Matriz quadrada: m = n (mesmo número de linhas e colunas).
  • Matriz diagonal: aij = 0 para i ≠ j.
  • Matriz identidade (In): diagonal principal com 1 e 0 fora.
  • Matriz nula: todos os elementos são zero.
  • Matriz transposta (AT): troca linhas por colunas.
  • Matriz simétrica: A = AT.
  • Matriz antissimétrica: A = –AT.

Operações com Matrizes

  • Adição: só possível com matrizes de mesma ordem; soma-se elemento a elemento.
  • Multiplicação por escalar: multiplica-se cada elemento pelo número.
  • Multiplicação de matrizes: A (m×p) × B (p×n) = C (m×n); cij = Σ aikbkj.
Exemplo: A = [[1, 2], [3, 4]] e B = [[2, 0], [1, 3]]; A·B = [[1·2+2·1, 1·0+2·3], [3·2+4·1, 3·0+4·3]] = [[4, 6], [10, 12]].

🔢 Determinantes

O determinante é um número associado a uma matriz quadrada. Indica se a matriz é invertível (det ≠ 0) e tem aplicações em sistemas lineares e transformações.

Cálculo de Determinantes

  • 2×2: det [[a, b], [c, d]] = ad – bc.
  • 3×3: Regra de Sarrus (repete as duas primeiras colunas, soma produtos diagonais, subtrai produtos da diagonal inversa).
  • n×n: Expansão por cofatores (Laplace).

Propriedades

  • det(A·B) = det(A) · det(B).
  • det(AT) = det(A).
  • Se uma linha/coluna é zero, det = 0.
  • Se duas linhas/colunas são iguais, det = 0.
  • Trocar linhas/colunas altera o sinal do determinante.
Exemplo: det [[2, 3], [4, 5]] = 2·5 – 3·4 = 10 – 12 = –2.

🧮 Sistemas Lineares

Um sistema linear é um conjunto de equações lineares. Pode ser escrito na forma matricial AX = B, onde A é a matriz dos coeficientes, X é o vetor das incógnitas e B é o vetor dos termos independentes.

Métodos de Resolução

  • Eliminação de Gauss: transforma o sistema em uma matriz escalonada.
  • Regra de Cramer: xi = det(Ai) / det(A), onde Ai substitui a coluna i por B.
  • Matriz inversa: X = A–1B, se A for invertível.

Classificação

  • SPD: Sistema Possível e Determinado (uma única solução).
  • SPI: Sistema Possível e Indeterminado (infinitas soluções).
  • SI: Sistema Impossível (nenhuma solução).
Exemplo: 2x + y = 5, x – y = 1. Matricial: [[2,1],[1,–1]] [x,y] = [5,1]. Solução: x=2, y=1.

➡️ Vetores

Um vetor é um segmento orientado com direção, sentido e magnitude. Pode ser representado como uma matriz coluna ou por coordenadas.

Operações com Vetores

  • Adição: soma-se coordenada a coordenada.
  • Multiplicação por escalar: multiplica-se cada coordenada.
  • Produto escalar (interno): u·v = u1v1 + ... + unvn.
  • Norma (módulo): ||u|| = √(u·u).
  • Ângulo entre vetores: cos θ = (u·v) / (||u||·||v||).

Dependência Linear

Um conjunto de vetores é linearmente dependente (LD) se um deles pode ser escrito como combinação linear dos outros. Caso contrário, é linearmente independente (LI).

Vetores LI formam uma base do espaço vetorial. Qualquer vetor do espaço pode ser escrito como combinação linear dos vetores da base.
Exemplo: v1 = (1,0), v2 = (0,1) são LI e formam a base canônica de ℝ².

🔄 Transformações Lineares

Uma transformação linear T: ℝn → ℝm é uma função que preserva as operações de adição e multiplicação por escalar: T(u+v) = T(u)+T(v) e T(cu) = cT(u).

Toda transformação linear é representada por uma matriz M, tal que T(v) = M·v.

Exemplos de Transformações

  • Rotação: gira vetores em torno da origem.
  • Reflexão: espelha vetores em relação a um eixo.
  • Escala: multiplica coordenadas por fatores.
  • Projeção: projeta vetores sobre uma reta ou plano.
Exemplo: Reflexão em relação ao eixo x: T(x,y) = (x,–y). Matriz: [[1,0],[0,–1]].

🎯 Autovalores e Autovetores

Dada uma matriz quadrada A, um autovetor v (não nulo) e seu autovalor λ satisfazem:

A·v = λ·v

Geometricamente, a transformação A atua sobre o autovetor apenas esticando/encolhendo, sem mudar a direção.

Como calcular

  1. Resolva a equação característica: det(A – λI) = 0.
  2. Encontre as raízes λ (autovalores).
  3. Para cada λ, resolva (A – λI)v = 0 para encontrar os autovetores.
Exemplo: A = [[2, 1], [1, 2]]. det(A–λI) = (2–λ)²–1 = 0 → λ=1 ou 3. Autovetores: para λ=1, v=(1,–1); para λ=3, v=(1,1).
Autovalores e autovetores são fundamentais em áreas como mecânica quântica, processamento de sinais, análise de redes e sistemas dinâmicos.

🌍 Álgebra Linear no Cotidiano

A álgebra linear está presente em diversas áreas – desde redes sociais até engenharia e economia.

📱 1. Redes Sociais (Matriz de Adjacência) Grafos

Uma rede social com 3 usuários tem as seguintes conexões: A segue B e C; B segue A; C segue A e B. Construa a matriz de adjacência e determine quantos caminhos de comprimento 2 existem de A para C.

Solução: Matriz M (linhas = quem segue, colunas = seguidos): M = [[0,1,1],[1,0,0],[1,1,0]].
M² dá o número de caminhos de comprimento 2. M² = [[2,1,0],[0,1,1],[1,1,1]].
De A (linha 1) para C (coluna 3) → M²[1,3] = 0 caminhos.
Interpretação: Não há caminho de comprimento exato 2 de A para C.
📊 2. Custo de Produção (Sistemas Lineares) Economia

Uma fábrica produz 3 produtos. Para cada unidade, consome: Produto A: 2h de máquina, 1h de mão de obra; Produto B: 1h máquina, 3h obra; Produto C: 3h máquina, 2h obra. Se há 50h de máquina e 40h de obra disponíveis, quantas unidades de cada produto podem ser fabricadas?

Solução: Sistema: 2x + y + 3z = 50 (máquina); x + 3y + 2z = 40 (obra).
Resolvendo (exemplo: x=10, y=8, z=4 verifica: 20+8+12=40? Não, 20+8+12=40, mas máquina: 20+8+12=40, não 50. Vou ajustar: x=10, y=10, z=10 → máquina 20+10+30=60, obra 10+30+20=60. Não fecha. Vou simplificar: resolvendo por eliminação: 2x+y+3z=50; x+3y+2z=40. Multiplicando a segunda por 2: 2x+6y+4z=80. Subtraindo: 5y+z=30 → z=30–5y. Substituindo em x+3y+2(30–5y)=40 → x+3y+60–10y=40 → x–7y=–20 → x=7y–20. Para y=5, z=5, x=15 → verifica: máquina:30+5+15=50, obra:15+15+10=40. Solução: 15,5,5.
Interpretação: 15 unidades de A, 5 de B e 5 de C.
🧭 3. Navegação por Satélite (Transformações) Geometria

Um satélite gira em torno da Terra. A rotação de um vetor (x,y) por um ângulo θ é dada pela transformação linear: T(x,y) = (x cos θ – y sen θ, x sen θ + y cos θ). Qual a matriz que representa essa rotação para θ = 90°?

Solução: Para θ = 90°, cos=0, sen=1. T(x,y) = (–y, x). Matriz: [[0, –1], [1, 0]].
Interpretação: Rotação de 90° no sentido anti-horário.
📈 4. Análise de Componentes Principais (Autovalores) Estatística

Uma matriz de covariância de dados tem autovalores λ₁ = 10 e λ₂ = 1. Qual a porcentagem de variância explicada pelo primeiro componente principal?

Solução: Variância total = 10 + 1 = 11. Proporção do primeiro = 10/11 ≈ 0,909 = 90,9%.
Interpretação: O primeiro componente principal explica cerca de 91% da variância dos dados.
🔐 5. Criptografia (Matrizes Inversas) Segurança

Uma mensagem é codificada pela matriz A = [[2, 1], [1, 3]]. A matriz inversa decodifica. Calcule A⁻¹.

Solução: det(A) = 2·3 – 1·1 = 5. A⁻¹ = (1/5) [[3, –1], [–1, 2]] = [[3/5, –1/5], [–1/5, 2/5]].
Interpretação: Multiplicando a mensagem codificada por A⁻¹, recuperamos o texto original.
⚡ 6. Circuitos Elétricos (Leis de Kirchhoff) Engenharia

Em um circuito com 3 malhas, as correntes i₁, i₂, i₃ satisfazem: 2i₁ – i₂ = 5; –i₁ + 3i₂ – i₃ = 2; –i₂ + 2i₃ = 1. Resolva o sistema.

Solução: Matricial: [[2,–1,0],[–1,3,–1],[0,–1,2]] · [i₁,i₂,i₃] = [5,2,1].
Resolvendo (por exemplo, por eliminação): i₁ = 3, i₂ = 1, i₃ = 1.
Interpretação: Correntes: i₁=3A, i₂=1A, i₃=1A.
