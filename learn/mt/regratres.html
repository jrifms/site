📖 Teoria da Regra de Três Simples

🔹 O que é Regra de Três Simples?

A regra de três simples é um método prático para resolver problemas que envolvem quatro valores, dos quais três são conhecidos e um é desconhecido, e que apresentam uma relação de proporcionalidade entre duas grandezas.

⏳ Dica de ouro: A regra de três é usada quando você tem duas grandezas que se relacionam de forma direta ou inversamente proporcional.

🔸 Grandezas Diretamente Proporcionais

Duas grandezas são diretamente proporcionais quando, aumentando uma delas, a outra aumenta na mesma proporção (e vice‑versa).

Exemplo: Velocidade × Distância (tempo constante) – quanto maior a velocidade, maior a distância percorrida.
Grandeza A ⬇ mesmo sentido ⬇ Grandeza B
Se A aumenta, B aumenta — setas para o mesmo lado
Problema: Um carro percorre 300 km com 40 litros. Quantos litros para 450 km?
Montagem com setas (mesmo sentido → direta):
300 km ⬇ ⟶ 40 L ⬇
450 km ⬇ ⟶ x L ⬇
Resolução: 300/450 = 40/x → 300x = 450·40 → x = (450·40)/300 = 60 L

🔸 Grandezas Inversamente Proporcionais

Duas grandezas são inversamente proporcionais quando, aumentando uma delas, a outra diminui na mesma proporção (e vice‑versa).

Exemplo: Velocidade × Tempo (distância constante) – quanto maior a velocidade, menor o tempo gasto.
Grandeza A ⬇ sentidos opostos ⬆ Grandeza B
Se A aumenta, B diminui — setas invertidas
Problema: Um trem a 80 km/h leva 3 horas. Se aumentar para 120 km/h, quanto tempo levará?
Montagem com setas (sentidos opostos → inversa):
80 km/h ⬇ ⟷ 3 h ⬆
120 km/h ⬇ ⟷ x h ⬆
Resolução (invertemos uma razão): 80/120 = x/3 → 120x = 80·3 → x = (80·3)/120 = 2 h

🔸 Como identificar direta ou inversa?

  • Direta: uma aumenta → a outra aumenta; uma diminui → a outra diminui.
  • Inversa: uma aumenta → a outra diminui; uma diminui → a outra aumenta.
🧠 Dica prática: Pergunte: "Se eu dobrar a primeira, o que acontece com a segunda?" Se também dobra → direta; se cai pela metade → inversa.

🔸 Passo a passo com setas

  1. Identifique as duas grandezas.
  2. Determine se é direta ou inversa (pense no efeito de aumentar uma grandeza).
  3. Monte a tabela com os valores e desenhe as setas (mesmo sentido → direta; sentidos opostos → inversa).
  4. Monte a proporção: se for direta, razões no mesmo sentido; se for inversa, inverta uma das razões.
  5. Multiplique cruzado e resolva a equação.

🧠 Macetes & Mnemônicos

📌 "D = D" – Direta

Direta → Dobro (se uma dobra, a outra também dobra).
Lembre: "Direta = mesma direção" (setas para o mesmo lado).

📌 "I = Contrária" – Inversa

Inversa → Invertida (se uma dobra, a outra cai pela metade).
Lembre: "Inversa = setas invertidas".

📌 "Regra do 'Se' "

  • Se aumentar uma grandeza e a outra aumentar → direta.
  • Se aumentar uma grandeza e a outra diminuir → inversa.

📌 "Multiplicação em Cruz"

Direta: a/b = c/x → a·x = b·c → x = (b·c)/a
Inversa: a/b = x/c → a·c = b·x → x = (a·c)/b

📌 "Tabelinha das Setas"

Escreva os dados em colunas, coloque setas para baixo em ambas. Se as setas estiverem no mesmo sentido → direta. Se sentidos opostos → inversa (inverta uma das razões).
