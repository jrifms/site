📌 Limite de uma Função

Definição intuitiva: O limite de f(x) quando x se aproxima de um valor a é o valor L que f(x) se aproxima arbitrariamente, desde que x esteja suficientemente próximo de a (mas não necessariamente igual a a).

Notação: limx→a f(x) = L

Definição formal (ε-δ): Para todo ε > 0, existe δ > 0 tal que se 0 < |x – a| < δ, então |f(x) – L| < ε.

Exemplo: limx→2 (2x + 1) = 5. Quando x se aproxima de 2, f(x) se aproxima de 5.
f(x) = x² – 2x + 1 (azul) · limite em x=2 (ponto destacado)

🔧 Como calcular um limite algebricamente

  1. Substituição direta: se f(a) existe, limx→a f(x) = f(a).
  2. Fatoração: se houver indeterminação (0/0), fatore e simplifique.
  3. Racionalização: multiplique pelo conjugado para eliminar raízes.
  4. Divisão pelo termo de maior grau: para limites no infinito.
Exemplo: limx→2 (x² – 4)/(x – 2) = limx→2 (x–2)(x+2)/(x–2) = limx→2 (x+2) = 4.

⚙️ Propriedades dos Limites

Se limx→a f(x) = L e limx→a g(x) = M, então:

  • Soma: lim (f + g) = L + M
  • Diferença: lim (f – g) = L – M
  • Produto: lim (f · g) = L · M
  • Quociente: lim (f / g) = L / M, se M ≠ 0
  • Potência: lim (fn) = Ln
  • Raiz: lim √f = √L (se L ≥ 0)
  • Multiplicação por constante: lim (c·f) = c·L
Teorema do confronto (Sanduíche): Se g(x) ≤ f(x) ≤ h(x) para x próximo de a, e lim g(x) = lim h(x) = L, então lim f(x) = L.

🌟 Limites Fundamentais

1. limx→0 sen x / x = 1
2. limx→0 (1 – cos x) / x = 0
3. limx→0 (ex – 1) / x = 1
4. limx→0 (1 + x)1/x = e
5. limx→0 ln(1 + x) / x = 1
Exemplo: limx→0 sen(2x)/x = 2 · limx→0 sen(2x)/(2x) = 2 · 1 = 2.
sen x / x (azul) · tende a 1 quando x→0

🔗 Continuidade

Uma função f é contínua em x = a se as três condições forem satisfeitas:

  1. f(a) existe (a pertence ao domínio).
  2. limx→a f(x) existe.
  3. limx→a f(x) = f(a).

Se uma dessas falha, a função é descontínua em a.

Exemplo: f(x) = (x² – 1)/(x – 1) não é contínua em x = 1, mas é contínua em todo outro ponto.
Teorema do Valor Intermediário: Se f é contínua em [a, b] e y está entre f(a) e f(b), então existe c ∈ (a, b) tal que f(c) = y.

📈 Derivada – Definição

A derivada de uma função f em um ponto x é a taxa de variação instantânea, definida pelo limite:

f'(x) = limh→0 (f(x+h) – f(x)) / h

Interpretação geométrica: a derivada é a inclinação da reta tangente ao gráfico de f no ponto (x, f(x)).

🔧 Como calcular a derivada pela definição

  1. Calcule f(x+h).
  2. Calcule f(x+h) – f(x).
  3. Divida por h.
  4. Calcule o limite quando h → 0.
Exemplo: f(x) = x² → f'(x) = limh→0 ((x+h)² – x²)/h = limh→0 (2xh + h²)/h = limh→0 (2x + h) = 2x.
f(x) = x² (azul) · reta tangente em x=1 (vermelha) · inclinação = f'(1) = 2

📊 Regras de Derivação

  • Regra da constante: d/dx [c] = 0
  • Regra da potência: d/dx [xn] = n·xn–1
  • Regra da soma: d/dx [f + g] = f' + g'
  • Regra do produto: d/dx [f·g] = f'·g + f·g'
  • Regra do quociente: d/dx [f/g] = (f'·g – f·g') / g²
  • Regra da cadeia: d/dx [f(g(x))] = f'(g(x)) · g'(x)
Exemplo (produto): f(x) = x²·sen x → f'(x) = 2x·sen x + x²·cos x.
Exemplo (cadeia): f(x) = (x² + 1)³ → f'(x) = 3(x² + 1)² · 2x = 6x(x² + 1)².

📋 Derivadas de Funções Elementares

  • d/dx [xn] = n·xn–1
  • d/dx [ex] = ex
  • d/dx [ax] = ax·ln a
  • d/dx [ln x] = 1/x
  • d/dx [loga x] = 1/(x·ln a)
  • d/dx [sen x] = cos x
  • d/dx [cos x] = –sen x
  • d/dx [tg x] = sec² x
  • d/dx [cotg x] = –cossec² x
  • d/dx [sec x] = sec x · tg x
  • d/dx [cossec x] = –cossec x · cotg x
Derivada da inversa: (f⁻¹)'(x) = 1 / f'(f⁻¹(x)).

🎯 Aplicações da Derivada

  • Reta tangente: y – f(a) = f'(a)(x – a).
  • Reta normal: y – f(a) = –1/f'(a)·(x – a) (se f'(a) ≠ 0).
  • Velocidade instantânea: v(t) = s'(t).
  • Aceleração: a(t) = v'(t) = s''(t).
  • Taxa de variação: dy/dx = f'(x).
  • Pontos críticos: onde f'(x) = 0 ou não existe (máximos, mínimos, inflexão).
  • Teste da derivada primeira: f' muda de + para – → máximo local; de – para + → mínimo local.
  • Teste da derivada segunda: f''(x) > 0 → mínimo local; f''(x) < 0 → máximo local.
Exemplo: f(x) = x³ – 3x² + 2. f'(x) = 3x² – 6x = 3x(x – 2). Pontos críticos: x = 0 (máximo local), x = 2 (mínimo local).
f(x) = x³ – 3x² + 2 (azul) · máx em x=0 · mín em x=2
