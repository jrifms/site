📊 Estatística Descritiva

A estatística descritiva tem como objetivo resumir e organizar dados, tornando-os mais fáceis de interpretar. Ela utiliza tabelas, gráficos e medidas resumo.

Tipos de Dados

  • Qualitativos (categóricos): nominais (sem ordem, ex: cor) ou ordinais (com ordem, ex: escolaridade).
  • Quantitativos (numéricos): discretos (contáveis, ex: número de filhos) ou contínuos (mensuráveis, ex: altura, peso).

Distribuição de Frequências

Organiza os dados em classes (intervalos) e conta a frequência de cada classe. Elementos: frequência absoluta, relativa, percentual, acumulada.

Exemplo: Notas de 20 alunos: 5,6,7,8,9,10... Agrupar em classes 0-4, 5-6, 7-8, 9-10.

Gráficos

  • Barras/Colunas: para dados qualitativos ou discretos.
  • Histograma: para dados contínuos (área proporcional à frequência).
  • Setores (Pizza): para proporções.
  • Boxplot: mostra mediana, quartis e outliers.

📈 Medidas de Tendência Central

Indicam o valor central ou típico de um conjunto de dados.

  • Média (aritmética): x̄ = (Σxi) / n. É influenciada por valores extremos.
  • Mediana: valor central quando os dados estão ordenados. Para n ímpar é o valor do meio; para n par, a média dos dois valores centrais. Não é influenciada por extremos.
  • Moda: valor que mais se repete. Pode haver mais de uma moda (bimodal, multimodal).
Média = Σx / n  ·  Mediana = valor central  ·  Moda = valor mais frequente
Exemplo: Dados: 2,3,5,7,8. Média=5, Mediana=5, Moda=não tem.

Escolha da medida: Em distribuições simétricas, média = mediana. Com assimetria, a mediana é mais robusta.

📉 Medidas de Dispersão

Indicam o grau de variabilidade ou espalhamento dos dados em torno da média.

  • Amplitude: máximo – mínimo. Muito sensível a outliers.
  • Variância (σ² ou s²): média dos quadrados dos desvios em relação à média.
  • Desvio padrão (σ ou s): raiz quadrada da variância. Mesma unidade dos dados.
  • Coeficiente de variação (CV): (desvio padrão / média) × 100%. Útil para comparar variabilidade de conjuntos com médias diferentes.
  • Amplitude interquartil (AIQ): Q3 – Q1. Medida robusta de dispersão.
σ² = Σ(xi – μ)² / N  ·  s² = Σ(xi – x̄)² / (n–1)  ·  CV = (s / x̄) × 100%
Exemplo: Dados 2,4,6,8. Média=5. Variância = [(–3)²+(–1)²+1²+3²]/4 = (9+1+1+9)/4 = 5. Desvio padrão = √5 ≈ 2,24.

🎲 Probabilidade

A probabilidade é a base da inferência estatística. Mede a chance de um evento ocorrer.

  • Definição clássica: P(A) = número de casos favoráveis / número de casos possíveis.
  • Definição frequentista: P(A) = limite da frequência relativa quando n→∞.
  • Propriedades: 0 ≤ P(A) ≤ 1; P(Ω)=1; P(∅)=0.

Regras

  • Soma: P(A∪B) = P(A) + P(B) – P(A∩B).
  • Produto (independentes): P(A∩B) = P(A)·P(B).
  • Probabilidade condicional: P(A|B) = P(A∩B) / P(B), com P(B) > 0.
  • Teorema de Bayes: P(A|B) = P(B|A)·P(A) / P(B).
Exemplo: Lançar um dado: P(par) = 3/6 = 0,5.

📊 Distribuições de Probabilidade

Distribuições Discretas

  • Binomial: número de sucessos em n tentativas independentes (p = probabilidade de sucesso). P(X=k) = C(n,k) pk (1–p)n–k. E(X)=np, Var(X)=np(1–p).
  • Poisson: número de eventos raros em um intervalo fixo (λ = taxa média). P(X=k) = e–λ λk / k!. E(X)=λ, Var(X)=λ.

Distribuições Contínuas

  • Normal (Gaussiana): f(x) = (1/(σ√(2π))) e–(x–μ)²/(2σ²). Simétrica, com média = mediana = moda. 68% dos dados em μ±σ, 95% em μ±2σ, 99,7% em μ±3σ.
  • Padronização (Z): Z = (X – μ) / σ. Z ∼ N(0,1).
  • t-Student: usada para amostras pequenas (n < 30) quando a variância populacional é desconhecida.
  • Qui-quadrado (χ²): usada em testes de ajuste e independência.
  • F de Snedecor: usada em ANOVA e comparação de variâncias.
Teorema do Limite Central (TLC): Para amostras suficientemente grandes (n ≥ 30), a distribuição das médias amostrais se aproxima de uma normal, independentemente da distribuição da população.

🔍 Inferência Estatística

A inferência permite tirar conclusões sobre a população a partir de uma amostra.

Estimativa Pontual

Usa uma estatística (ex: média amostral x̄) para estimar um parâmetro populacional (μ). É um valor único, sujeito a erro.

Intervalos de Confiança

Fornece um intervalo de valores que contém o parâmetro com uma certa probabilidade (nível de confiança, geralmente 95%).

  • Para μ com σ conhecido: x̄ ± z·(σ/√n).
  • Para μ com σ desconhecido (n ≥ 30): x̄ ± z·(s/√n).
  • Para μ com σ desconhecido (n < 30): x̄ ± t·(s/√n), com t da distribuição t-Student com n–1 graus de liberdade.
  • Para proporção p: p̂ ± z·√(p̂(1–p̂)/n).
Exemplo: Amostra n=100, x̄=50, s=10. IC 95% para μ: 50 ± 1,96·(10/√100) = 50 ± 1,96 = [48,04, 51,96].

📋 Testes de Hipóteses

Procedimento para decidir se uma afirmação sobre a população é verdadeira, com base em dados amostrais.

  • Hipótese nula (H₀): afirmação a ser testada (ex: μ = μ₀).
  • Hipótese alternativa (H₁): o que se quer evidenciar (ex: μ ≠ μ₀, μ > μ₀, μ < μ₀).
  • Estatística de teste: valor calculado a partir dos dados (ex: z, t, χ², F).
  • Nível de significância (α): probabilidade de erro tipo I (rejeitar H₀ quando verdadeira).
  • Valor-p (p-value): probabilidade de obter um resultado tão extremo quanto o observado, supondo H₀ verdadeira. Se p < α, rejeita-se H₀.

Testes Comuns

  • Teste z: para média com variância conhecida (n ≥ 30).
  • Teste t: para média com variância desconhecida (n < 30).
  • Teste χ² de independência: para tabelas de contingência (duas variáveis categóricas).
  • Teste χ² de aderência (bondade de ajuste): compara distribuição observada com esperada.
  • ANOVA (Análise de Variância): compara médias de três ou mais grupos.
Exemplo: H₀: μ = 50 vs H₁: μ ≠ 50. α=0,05. Amostra n=30, x̄=52, s=4. z = (52–50)/(4/√30) = 2,74. p-valor = 0,006 < 0,05 → rejeita H₀. Conclusão: há evidência de que a média é diferente de 50.

📈 Regressão e Correlação

Estuda a relação entre duas ou mais variáveis.

Correlação

  • Coeficiente de correlação de Pearson (r): mede a intensidade e direção da relação linear entre duas variáveis. r ∈ [–1, 1]. r próximo de 1 → correlação positiva forte; r próximo de –1 → negativa forte; r = 0 → ausência de correlação linear.
r = Σ[(xi–x̄)(yi–ȳ)] / √[Σ(xi–x̄)² · Σ(yi–ȳ)²]

Regressão Linear Simples

Modelo: y = a + bx + ε, onde a é o intercepto, b é a inclinação (efeito de x sobre y), ε é o erro aleatório.

  • Coeficientes estimados (mínimos quadrados): b = Σ(xi–x̄)(yi–ȳ) / Σ(xi–x̄)²; a = ȳ – b·x̄.
  • Coeficiente de determinação (R²): proporção da variância de y explicada pelo modelo. R² = r² (na regressão simples).
Exemplo: Dados de horas de estudo (x) e nota (y). Estimar nota para x=5. Suponha que a regressão seja y = 4 + 1,5x. Para x=5 → y = 4 + 7,5 = 11,5.

Regressão Múltipla

Inclui mais de uma variável preditora: y = a + b₁x₁ + b₂x₂ + ... + bkxk + ε. Avalia o efeito conjunto e individual de cada preditor.

🌍 Estatística no Cotidiano

A estatística está presente em pesquisas, negócios, saúde, esportes e muito mais.

📊 1. Média de Notas (Descritiva) Educação

As notas de 5 alunos foram: 6, 7, 8, 9, 10. Calcule a média, mediana e desvio padrão.

Solução:
Média = (6+7+8+9+10)/5 = 40/5 = 8.
Mediana = valor central (ordenados) = 8.
Variância = [(–2)²+(–1)²+0²+1²+2²]/5 = (4+1+0+1+4)/5 = 10/5 = 2.
Desvio padrão = √2 ≈ 1,41.
Interpretação: A média é 8, a mediana é 8 e o desvio é 1,41 (baixa dispersão).
🎲 2. Probabilidade de uma Moeda Jogos

Uma moeda é lançada 3 vezes. Qual a probabilidade de obter exatamente 2 caras?

Solução:
Usando a distribuição binomial: n=3, k=2, p=0,5.
P(X=2) = C(3,2) · (0,5)² · (0,5)¹ = 3 · 0,25 · 0,5 = 0,375 = 37,5%.
Interpretação: Em 37,5% das vezes, sairão exatamente 2 caras.
📈 3. Intervalo de Confiança (Pesquisa) Opinião

Uma pesquisa com 400 pessoas mostrou que 60% são a favor de uma proposta. Construa um IC de 95% para a proporção populacional.

Solução:
p̂ = 0,6; n=400; z(95%) = 1,96.
Erro = z·√(p̂(1–p̂)/n) = 1,96·√(0,6·0,4/400) = 1,96·√(0,0006) ≈ 1,96·0,0245 = 0,048.
IC = 0,6 ± 0,048 = [0,552; 0,648] ou [55,2%; 64,8%].
Interpretação: Com 95% de confiança, a proporção real está entre 55,2% e 64,8%.
🧪 4. Teste de Hipóteses (Medicina) Saúde

Um medicamento afirma reduzir a pressão arterial em 5 mmHg, em média. Em uma amostra de 30 pacientes, a redução média foi de 4,2 mmHg com desvio 1,8. Teste a afirmação com α=0,05.

Solução:
H₀: μ = 5; H₁: μ ≠ 5 (bilateral).
t = (4,2 – 5) / (1,8/√30) = –0,8 / 0,3286 = –2,43.
Graus de liberdade = 29. p-valor ≈ 0,021 (bilateral).
Como p < 0,05, rejeita-se H₀. Há evidência de que a redução média não é 5 mmHg.
Interpretação: O medicamento não atinge a redução prometida.
📉 5. Correlação e Regressão (Vendas) Negócios

Uma loja coletou dados de gastos com publicidade (x, em mil R$) e vendas (y, em mil R$): (1, 10), (2, 14), (3, 18), (4, 22). Estime as vendas para um gasto de 5 mil R$.

Solução:
x̄ = 2,5; ȳ = 16. Σ(x–x̄)(y–ȳ) = (–1,5·–6)+(–0,5·–2)+(0,5·2)+(1,5·6) = 9+1+1+9=20. Σ(x–x̄)² = 2,25+0,25+0,25+2,25=5.
b = 20/5 = 4; a = 16 – 4·2,5 = 16 – 10 = 6.
Equação: y = 6 + 4x. Para x=5 → y = 6 + 20 = 26 mil R$.
Interpretação: Com gasto de 5 mil em publicidade, as vendas estimadas são 26 mil.
📦 6. Distribuição Normal (Controle de Qualidade) Indústria

O peso de um produto tem distribuição normal com μ=200g e σ=5g. Qual a probabilidade de um produto pesar entre 195g e 205g?

Solução:
P(195 < X < 205) = P((195–200)/5 < Z < (205–200)/5) = P(–1 < Z < 1).
P(–1 < Z < 1) = 0,6827 (pela tabela normal).
Interpretação: 68,27% dos produtos estão nesse intervalo (regra empírica).
