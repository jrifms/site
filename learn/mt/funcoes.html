📈 Função Afim (1º grau)

Definição: Toda função f: ℝ → ℝ dada por f(x) = ax + b, com a ≠ 0, é chamada de função afim.

  • a = coeficiente angular (taxa de variação) → determina a inclinação da reta.
  • b = coeficiente linear → ponto onde a reta cruza o eixo y (0, b).
  • Gráfico: uma reta.
  • Raiz (zero): x = –b/a.
Fórmula geral: f(x) = ax + b  ·  a ≠ 0

🔧 Como construir a função a partir de dois pontos

Dados dois pontos P(x₁, y₁) e Q(x₂, y₂) com x₁ ≠ x₂:

  1. Calcule a = (y₂ – y₁) / (x₂ – x₁).
  2. Substitua um dos pontos e o valor de a em y = ax + b para encontrar b.
  3. Escreva f(x) = ax + b.
Exemplo: P(1, 2) e Q(3, 8) → a = (8–2)/(3–1) = 6/2 = 3.
2 = 3·1 + b → b = –1. Logo f(x) = 3x – 1.
f(x) = 2x + 3 (azul)  ·  f(x) = –x + 4 (vermelho)

Propriedades importantes

  • Crescente: se a > 0.
  • Decrescente: se a < 0.
  • Constante: se a = 0 (não é afim, é constante).
  • Função linear: b = 0 → f(x) = ax (passa pela origem).

📊 Função Quadrática (2º grau)

Definição: Toda função f: ℝ → ℝ dada por f(x) = ax² + bx + c, com a ≠ 0.

  • a → concavidade: a > 0 (∪), a < 0 (∩).
  • Δ = b² – 4ac (discriminante).
  • Raízes (zeros): x = (–b ± √Δ) / 2a (Bhaskara).
  • Vértice: V = (–b/2a, –Δ/4a).
  • Eixo de simetria: x = –b/2a.
Forma geral: f(x) = ax² + bx + c  ·  a ≠ 0

🔧 Como construir a partir das raízes

Se conhecermos as raízes x₁ e x₂, podemos escrever:

f(x) = a(x – x₁)(x – x₂) (forma fatorada).

Para determinar a, usamos um ponto adicional.

Exemplo: Raízes 2 e 5 → f(x) = a(x – 2)(x – 5). Se f(3) = –4, então –4 = a(1)(–2) → a = 2. Logo f(x) = 2(x – 2)(x – 5) = 2x² – 14x + 20.
f(x) = x² – 4x + 3 (azul)  ·  f(x) = –x² + 2x + 3 (vermelho)

Formas de representação

  • Geral: f(x) = ax² + bx + c
  • Fatorada: f(x) = a(x – x₁)(x – x₂) (se Δ ≥ 0)
  • Canônica: f(x) = a(x – h)² + k, onde (h, k) é o vértice.

Completando quadrados: a partir de ax² + bx + c, podemos escrever na forma canônica para encontrar o vértice facilmente.

🚀 Função Exponencial

Definição: f: ℝ → ℝ+ dada por f(x) = ax, com a > 0 e a ≠ 1.

  • Base a determina o crescimento/decrescimento.
  • Se a > 1 → crescente.
  • Se 0 < a < 1 → decrescente.
  • Domínio: ℝ; Imagem: ℝ+ (positivos).
  • O gráfico passa por (0, 1) porque a⁰ = 1.
  • Assíntota horizontal: eixo x (y = 0).
Forma geral: f(x) = ax  ·  a > 0, a ≠ 1

🔧 Como construir a partir de dois pontos

Dados P(x₁, y₁) e Q(x₂, y₂) com y > 0:

  1. Use a relação y₁ = ax₁ e y₂ = ax₂.
  2. Divida: y₂/y₁ = ax₂–x₁ → a = (y₂/y₁)1/(x₂–x₁).
  3. Substitua para encontrar a função.
Exemplo: P(1, 2) e Q(3, 8) → a = (8/2)1/(3–1) = 41/2 = 2. Logo f(x) = 2x.
2x (azul)  ·  (½)x (vermelho)

Propriedades importantes

  • am · an = am+n
  • am / an = am–n
  • (am)n = am·n
  • a–n = 1 / an
  • a0 = 1

Aplicação: crescimento populacional, juros compostos, decaimento radioativo.

🔢 Função Logarítmica

Definição: f: ℝ+ → ℝ dada por f(x) = loga x, com a > 0, a ≠ 1 e x > 0.

  • É a função inversa da exponencial.
  • Se a > 1 → crescente; se 0 < a < 1 → decrescente.
  • Domínio: ℝ+ (x > 0); Imagem: ℝ.
  • O gráfico passa por (1, 0) porque loga 1 = 0.
  • Assíntota vertical: eixo y (x = 0).
Forma geral: f(x) = loga x  ·  a > 0, a ≠ 1, x > 0

🔧 Como construir a partir de pontos

Assim como a exponencial, podemos determinar a base a usando dois pontos e a definição de logaritmo.

Exemplo: Se f(2) = 1 e f(8) = 3, então loga 2 = 1 → a = 2, e log2 8 = 3 confirma. Logo f(x) = log2 x.
log₂ x (azul)  ·  log½ x (vermelho)

Propriedades dos logaritmos

  • loga (m·n) = loga m + loga n
  • loga (m/n) = loga m – loga n
  • loga mn = n · loga m
  • loga 1 = 0; loga a = 1
  • Mudança de base: loga b = logc b / logc a

🔄 Funções Trigonométricas

As funções seno, cosseno e tangente são definidas a partir do círculo trigonométrico.

🔵 Seno (f(x) = sen x)

  • Domínio: ℝ; Imagem: [–1, 1]
  • Período: 2π
  • Função ímpar: sen(–x) = –sen x
  • Zeros: x = kπ, k ∈ ℤ

🟢 Cosseno (f(x) = cos x)

  • Domínio: ℝ; Imagem: [–1, 1]
  • Período: 2π
  • Função par: cos(–x) = cos x
  • Zeros: x = π/2 + kπ, k ∈ ℤ

🟠 Tangente (f(x) = tg x = sen x / cos x)

  • Domínio: x ≠ π/2 + kπ, k ∈ ℤ
  • Imagem: ℝ
  • Período: π
  • Função ímpar: tg(–x) = –tg x
  • Zeros: x = kπ, k ∈ ℤ

Identidades fundamentais

  • sen² x + cos² x = 1
  • tg x = sen x / cos x
  • cotg x = cos x / sen x
  • sec x = 1 / cos x  ·  cossec x = 1 / sen x
  • sen(a ± b) = sen a cos b ± cos a sen b
  • cos(a ± b) = cos a cos b ∓ sen a sen b

🧩 Função Modular

Definição: f(x) = |x|, onde |x| = x se x ≥ 0 e |x| = –x se x < 0.

  • Domínio: ℝ; Imagem: [0, +∞)
  • Função par: |–x| = |x|
  • Gráfico em forma de "V" com vértice em (0, 0).
Definição por partes: |x| = { x, se x ≥ 0; –x, se x < 0 }

🔧 Transformações com módulo

  • |x| + c → deslocamento vertical (c > 0 sobe, c < 0 desce).
  • |x – h| → deslocamento horizontal (h > 0 para direita).
  • a|x| → alongamento/compressão vertical (|a| > 1 alonga).
  • |f(x)| → reflete a parte negativa de f para cima.
|x| (azul)  ·  |x – 2| + 1 (vermelho)

📌 Outras Funções Importantes

🧊 Função Raiz

Raiz quadrada: f(x) = √x, com x ≥ 0. Gráfico é uma parábola deitada.

Raiz cúbica: f(x) = ∛x, domínio ℝ. É ímpar.

√x (azul)  ·  ∛x (vermelho)

📦 Função Polinomial

f(x) = anxn + ... + a1x + a0, com an ≠ 0.

  • Grau n (maior expoente).
  • Exemplos: cúbica (n=3), quártica (n=4).
  • Gráfico pode ter várias curvas e pontos de inflexão.

🧮 Função Racional

f(x) = P(x) / Q(x), onde P e Q são polinômios, Q(x) ≠ 0.

  • Domínio: todos os reais, exceto raízes de Q.
  • Exemplo clássico: f(x) = 1/x (hipérbole).
  • Assíntotas verticais e horizontais.
1/x (azul)  ·  (x+1)/(x–2) (vermelho)

🔁 Função Inversa

Se f é bijetora, existe f⁻¹ tal que f(f⁻¹(x)) = x.

  • Gráfico da inversa é simétrico em relação à reta y = x.
  • Exemplo: f(x) = x² (x ≥ 0) → f⁻¹(x) = √x.
x² (x≥0) (azul)  ·  √x (vermelho)  ·  y=x (tracejado)
