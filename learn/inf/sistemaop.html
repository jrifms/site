🧠 O que é um Sistema Operacional?

  • Definição: software que gerencia hardware e recursos, fornecendo interface para o usuário.
  • Funções básicas: gerenciamento de processos, memória, arquivos, dispositivos E/S, segurança.
  • Tipos: desktop (Windows, Linux, macOS), servidor (Windows Server, Linux), mobile (Android, iOS).
  • Kernel: núcleo do SO, responsável pela comunicação entre software e hardware.
Principais sistemas operacionais.
💡 Macete: “SO é o gerente do computador: controla tudo, desde o mouse até a memória.”
📌 Decore: Kernel é o coração do SO.
📌 Dica de prova: “O Linux é open-source e gratuito; Windows e macOS são pagos.”

⚙️ Gerenciamento de Processos

  • Processo: programa em execução.
  • Thread: unidade menor de execução dentro de um processo.
  • Escalonamento: algoritmo que decide qual processo será executado pela CPU.
  • Estados do processo: pronto, executando, bloqueado, novo, terminado.
  • Comandos: no Windows, Ctrl+Alt+Del (Gerenciador de Tarefas); no Linux, ps, top, kill.
Estados básicos de um processo.
💡 Macete: “Pronto → Executando → Bloqueado → Pronto (ciclo).”
📌 Decore: O escalonador decide qual processo executa.
📌 Dica de prova: “No Windows, o Gerenciador de Tarefas mostra processos e threads.”

🧠 Gerenciamento de Memória

  • Memória virtual: utiliza espaço em disco (swap/paging) para estender a RAM.
  • Paginação: divide a memória em páginas (ex: 4KB).
  • Segmentação: divide em segmentos lógicos (código, dados, pilha).
  • Swapping: movimenta processos entre RAM e disco.
Conceito de memória virtual.
💡 Macete: “Memória virtual engana o programa, fazendo-o pensar que tem mais RAM.”
📌 Decore: Páginas são blocos de memória física.
📌 Dica de prova: “O arquivo de página (pagefile.sys no Windows) é usado para memória virtual.”

📁 Sistema de Arquivos

  • Estrutura: diretórios (pastas) e arquivos.
  • Tipos: NTFS (Windows), ext4 (Linux), APFS (macOS), FAT32, exFAT.
  • Permissões: leitura, escrita, execução.
  • Caminhos: absoluto (ex: C:\Users\... no Windows; /home/... no Linux) e relativo.
Sistemas de arquivos mais comuns.
💡 Macete: “NTFS é o padrão do Windows, ext4 do Linux, APFS do macOS.”
📌 Decore: FAT32 é compatível com vários SOs, mas tem limite de 4GB por arquivo.
📌 Dica de prova: “No Linux, tudo é arquivo (incluindo dispositivos).”

⌨️ Comandos – Windows e Linux

  • Windows (CMD): dir, cd, ipconfig, ping, tasklist.
  • Linux (Bash): ls, cd, pwd, ps, top, kill, ifconfig/ip.
  • Comandos comuns: mkdir, rm/rmdir, cp, mv.
Comandos mais cobrados em concursos.
💡 Macete: “No Windows, dir lista; no Linux, ls lista. Ambos têm cd.”
📌 Decore: ipconfig (Windows) e ifconfig/ip (Linux) mostram configurações de rede.
📌 Dica de prova: “No Linux, o comando sudo é usado para executar comandos com privilégios de administrador.”

⌨️ Atalhos de Teclado

  • Windows: Win (menu iniciar), Win+D (área de trabalho), Win+E (Explorador), Alt+Tab (alternar), Ctrl+Alt+Del (segurança).
  • Linux (Gnome/KDE): Super (Win) + D, Alt+Tab, Ctrl+Alt+T (terminal).
  • Comuns: Ctrl+C (copiar), Ctrl+V (colar), Ctrl+X (cortar), Ctrl+Z (desfazer).
Atalhos mais usados.
💡 Macete: “Win+D mostra a área de trabalho, Alt+Tab alterna entre janelas, Ctrl+Alt+Del abre o menu de segurança.”
📌 Decore: No Linux, a tecla Super é a tecla Windows.
📌 Dica de prova: “No Windows, Win+L bloqueia a tela; Ctrl+Shift+Esc abre o Gerenciador de Tarefas diretamente.”

📁 Extensões e associações

  • Executáveis: .exe (Windows), .bin (Linux), .app (macOS).
  • Scripts: .bat (Windows), .sh (Linux), .cmd (Windows).
  • Bibliotecas: .dll (Windows), .so (Linux), .dylib (macOS).
  • Pacotes: .msi (Windows), .deb/.rpm (Linux), .pkg (macOS).
Extensões de executáveis e scripts.
💡 Macete: “.exe é do Windows, .sh é script Linux, .app é aplicativo macOS.”
📌 Decore: No Linux, a extensão não define se é executável; a permissão de execução que conta.
📌 Dica de prova: “Um arquivo .dll (Windows) é uma biblioteca dinâmica; .so no Linux é biblioteca compartilhada.”

⚖️ Comparativo entre SOs

  • Windows: pago, maior compatibilidade de software, interface gráfica (GUI).
  • Linux: gratuito, open-source, várias distribuições (Ubuntu, Fedora, Debian).
  • macOS: pago, exclusivo para hardware Apple, baseado em Unix.
  • Mobile: Android (baseado em Linux), iOS (baseado em Unix).
Comparativo entre SOs.
💡 Macete: “Windows é pago e popular, Linux é livre e estável, macOS é exclusivo e integrado.”
📌 Decore: Linux é amplamente usado em servidores (cerca de 70% da web roda em Linux).
📌 Dica de prova: “O Android é baseado em Linux; o iOS é baseado em Unix (BSD).”

👤 Usuários e Permissões

  • Windows: Contas de usuário (Administrador, Padrão, Convidado) – UAC.
  • Linux: root (superusuário), usuários normais; permissões rwx.
  • Comandos: chmod, chown, useradd, passwd (Linux); net user (Windows).
Contas de usuário no Windows.
💡 Macete: “No Linux, root é o todo-poderoso; no Windows, Administrador tem poderes totais.”
📌 Decore: chmod 755 dá permissões rwxr-xr-x.
📌 Dica de prova: “O UAC (Windows) pede confirmação para ações que exigem privilégios de administrador.”

📌 Resumo para a Prova

  • SO: gerencia hardware e recursos.
  • Processos: estado (pronto, executando, bloqueado), escalonamento.
  • Memória: virtual, paginação, swapping.
  • Arquivos: sistemas de arquivos (NTFS, ext4, APFS), permissões.
  • Comandos: dir/ls, cd, ipconfig/ifconfig, tasklist/ps, kill.
  • Atalhos: Win+D, Alt+Tab, Ctrl+Alt+Del.
  • Extensões: .exe, .sh, .app, .dll, .so, .deb, .msi.
📌 Super Macete: “Decore: Windows = .exe, Linux = .sh, macOS = .app. Comandos: dir no Windows, ls no Linux.”
